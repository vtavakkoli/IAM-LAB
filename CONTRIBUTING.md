# Contributing Guide

> **Written by Vahid Tavakkoli, 2026**

Thanks for your interest in improving this IAM lab.

## Scope

Contributions should improve:

- documentation and usability
- reproducibility and developer experience
- reliability of existing behavior

Please avoid changing core authentication/authorization behavior unless explicitly discussed in an issue.

## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make focused changes with clear commit messages.
4. Validate locally (`docker compose config`, builds, formatting).
5. Open a pull request using the provided template.

## Pull request expectations

Include in your PR description:

- what changed
- why it changed
- how it was tested
- any limitations or follow-up items

## Style expectations

- Keep documentation concise and accurate.
- Prefer explicit examples over vague instructions.
- Do not commit secrets.
- Keep changes scoped and reviewable.

## Reporting issues

Use GitHub Issues and provide:

- reproduction steps
- expected vs actual behavior
- environment details
