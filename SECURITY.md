# Security Policy

## Reporting a vulnerability

If you discover a security issue, please do **not** open a public issue with exploit details.

Instead, report responsibly via private communication with maintainers, including:

- affected component(s)
- reproducible steps
- impact assessment
- suggested remediation (if known)

## Scope note

This repository is a lab/demo environment. Security weaknesses may exist by design to support learning scenarios.
